# Code of Conduct

## Our standard

We welcome rigorous disagreement and expect respectful, evidence-based discussion. Contributors should be specific about uncertainty, disclose limitations, protect confidential research, and give credit for prior work.

Harassment, discrimination, plagiarism, fabricated evidence, deceptive benchmark reporting, and attempts to expose confidential manuscripts are not acceptable.

## Enforcement

Report conduct concerns privately to the repository maintainer through the security contact or GitHub profile. Maintainers may edit, remove, or reject contributions and restrict participation when necessary to protect the community.

This concise code follows the spirit of the Contributor Covenant without reproducing it.
