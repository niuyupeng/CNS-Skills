# Support

Use [GitHub Issues](https://github.com/niuyupeng/CNS-Skills/issues) for reproducible bugs, installation problems, feature requests, and documentation questions. Use the private reporting process in [SECURITY.md](SECURITY.md) for security-sensitive findings.

When reporting a problem, include the CNS Skills version, host application and version, operating system, invocation method, minimal reproduction, and sanitized output. Do not attach confidential manuscripts, unpublished data, credentials, or full unredacted audit reports to a public issue.
