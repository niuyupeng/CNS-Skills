# Security and responsible disclosure

Do not open a public issue containing unpublished manuscripts, API keys, personal data, or confidential peer-review material.

For a security or privacy concern, contact the maintainer privately through the GitHub profile at <https://github.com/niuyupeng>. Include the affected version, a minimal reproduction, and the impact. Please allow a reasonable period for investigation before public disclosure.

The Crossref option sends extracted DOI strings to the public Crossref API. It does not upload the manuscript text.
