# Scientific integrity and claim–citation alignment

## Non-negotiable rules

1. Preserve the factual payload of the source draft unless evidence supports a change.
2. Never manufacture bibliographic metadata or experimental detail.
3. Place uncertainty at the claim, not in a distant disclaimer.
4. Distinguish observed results, author interpretation, review synthesis, and the reviser's inference.
5. Keep validation layers visible: computational only, retrospective, in vitro, ex vivo, animal, human observational, clinical/prospective, or real-world deployment.

## Claim strength ladder

| Evidence supports | Preferred language | Avoid without stronger evidence |
|---|---|---|
| association or prediction | associated with; predicted; was consistent with | caused; determined; established |
| one benchmark/data split | in this dataset; under this evaluation | generally; robustly; universally |
| in vitro result | in vitro; in cell-based assays | therapeutic; clinically effective |
| animal result | in this model; preclinical | safe/effective in patients |
| retrospective human data | retrospectively; in the studied cohort | prospective utility; clinical benefit |
| computational proposal | candidate; predicted design; in silico | discovered material; validated material |

## High-risk language

Require direct support for: first, unprecedented, superior, state of the art, universal, causal, safe, effective, clinically applicable, autonomous, closed loop, interpretable, generalizable, and real time.

Replace an unsupported superlative with a scoped comparison, or flag it for verification.

## Citation verification record

For each item checked, record:

- citation number or key;
- title as written;
- DOI or persistent identifier;
- authoritative lookup source;
- title/authors/year/journal match status;
- publication state;
- correction/retraction concern;
- notes on claim support.

DOI resolution proves existence, not entailment. Read the abstract/full text or authoritative record when a claim depends on methods, population, endpoint, or validation level.

## Evidence-boundary checklist

- Is prediction being described as discovery?
- Is correlation being described as mechanism?
- Is one material system generalized to a class?
- Is a favorable metric presented without baseline, split, or uncertainty?
- Is internal validation presented as external validation?
- Is a retrospective workflow described as prospective automation?
- Is an LLM-generated proposal described as experimental success?
- Is a review cited for a primary quantitative result?

If yes, narrow the wording or request evidence.
